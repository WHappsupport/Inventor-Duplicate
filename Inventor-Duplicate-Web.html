Effective date: 30-10-2026

1. Introduction

This an explaination on how the Duplicate app works, developed by Wander Heuvelman.

Installing

Only run installers from a trusted source, get your copy only and directly from the Autodesk marketplace. Restart Inventor after installing. After installment if the add-in does not load go in inventor to the add-ins button and unblock "Assembly Duplicate"

How does it work?

This Inventor add-in aims to duplicate the part or assembly selected including all underlying constraints (if they are not suppressed). If the constraints are suppressed then the add-in will skip these constraints. After a constraint is copied over to the copied part it will check for the degrees of freedom, if the constraint is not influenced by the degrees of freedom the constraint is removed again. If after all that the only constraint found is an insert constraint it will ask you to select new edges. When you select 1 or more edges it will copy the part and constraint the part or assembly to the selected edges.

Step by step functionality of the app

Step 1 – Select the part or assembly

The add-in checks the currently selected items:

  • If one item is selected, it will use that item (part or assembly).
  • If no item is selected, a selection picker will appear, allowing the user to select a part or assembly.
  • If two or more items are selected, the user will be prompted to select only one item, and the function will exit.

Step 2 – Store the assembly constraints

All constraints belonging to the selected part or assembly are collected and stored in a dictionary.

Step 3 – Create a duplicate occurrence

The occurrence matrix of the original part or assembly is copied. A second occurrence of the selected part or assembly is then created using the copied matrix, maintaining its original position and orientation.

Step 4 – Identify the original constraints

The add-in loops through all assembly constraints and checks whether each constraint is present in the dictionary created in Step 2.

Constraints are processed in their creation order. The reasoning is that constraints created first are likely to be more important than constraints created later.

Step 5 – Check whether the constraint is suppressed

Each identified constraint is checked to see whether it is suppressed. If a constraint is suppressed, it will be skipped and the add-in will continue with the next constraint.

Step 6 – Re-create the supported constraints

For Mate, Flush, Angle and Insert constraints, the add-in attempts to recreate each constraint on the newly created occurrence.

After creating a constraint, the add-in checks whether it influences the freedom of rotation.

If the newly created constraint does not influence the freedom of rotation, it will be removed again.

Tangent and Transitional constraints are currently not copied. Support for these constraint types may be implemented in a future update.

Step 7 – Validate the created constraints

The newly created part or assembly is checked again.

If it contains a single Insert constraint, the add-in will continue to the next step. If it contains anything else, the function will exit.

Step 8 – Hide the duplicate occurrence

The newly created occurrence is hidden. This prevents it from being selected accidentally in the next selection picker.

Step 9 – Select the target edges

A new selection picker is created, prompting the user to select one or multiple edges.

The user can continue selecting edges until the Escape key is pressed.

Step 10 – Create duplicates for the selected edges

For every selected edge, the add-in copies the part or assembly and recreates the corresponding constraint using the newly selected edge.

Once all selected edges have been processed, the functionality exits.

Known errors:

When a part from a subassembly is selected it will not recognize the constraint in the top assembly. (go to the subassembly instead)
