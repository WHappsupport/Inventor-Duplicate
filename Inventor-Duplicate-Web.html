1. Introduction

This an explaination on how the Duplicate app works, developed by Wander Heuvelman.

Installing

Only run installers from a trusted source, get your copy only and directly from the Autodesk marketplace. Restart Inventor after installing. After installment if the add-in does not load go in inventor to the add-ins button and unblock "Assembly Duplicate"

How does it work?

This Inventor add-in aims to duplicate the part or assembly selected including all underlying constraints (if they are not suppressed). If the constraints are suppressed then the add-in will skip these constraints. After a constraint is copied over to the copied part it will check for the degrees of freedom, if the constraint is not influenced by the degrees of freedom the constraint is removed again. If after all that the only constraint found is an insert constraint it will ask you to select new edges. When you select 1 or more edges it will copy the part and constraint the part or assembly to the selected edges.

Step by step functionality of the app

1st: Checks for one or more selected items: If 1 item is selected it will use that item (part or assembly) If no item is selected it will prompt a picker to select a part or assembly. When 2 or more items are selected it will prompt the user to only select 1 part and exit the function. 2nd: Add all constraints of the selected part or assembly to a dictionary 3rd: Copy the occurrence matrix of the original part/assembly Create a second occurrence of the selected part/assembly with the copy of the original matrix 4th: Loop through all the assembly constraints and check if they are in the previously created dictionary (of the second step) Reasoning that if a constraint is created first it will likely be more important than the second made constraint. 5th: Checks if the constraint from the fourth step is suppressed, if so go to the next constraint 6th: For a Mate, flush, angle and insert constraints it will copy every constraint found to the newly created occurrence. Check if the newly created constraint influences the freedom of rotation. If it does not influence the freedom of rotation it will remove the created constraint again. For tangent and transitional constraints the add-in will not copy the constraints. (to be possibly implemented later) 7th: It will check the created part again for the following: When it is a single insert constraint it will move on to the next, if anything else it will exit the function. 8th: Hide the newly created part (to not be able to select it in the next picker). 9th: Create a picker and request you to select 1 or multiple edges until pressed Esc. 10th: for each selected edge it will copy the part or assembly and re-create the constraint to the newly selected edges. Exit functionality

Known errors:

When a part from a subassembly is selected it will not recognize the constraint in the top assembly. (go to the subassembly instead)
